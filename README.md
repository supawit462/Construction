# Baiboon Home — เว็บไซต์หน้าเดียว

เว็บ one-page 6 section สำหรับ **Baiboon Home รับสร้างบ้านครบวงจร**
ใช้ CI จากโพสต์รีแบรนด์ของเพจ และใช้โครงเว็บ pd.co.th เป็นแนวทาง (ออกแบบ Hero ใหม่)

เปิด `index.html` ในเบราว์เซอร์ได้ทันที ไม่ต้อง build

## โครงหน้า
1. **Hero** — ข้อความ "เริ่มก้าวใหม่ที่อบอุ่น" + ภาพบ้านในกรอบโค้ง + การ์ดลอย
2. **เกี่ยวกับเรา** — "ชื่อใหม่… แต่หัวใจเดิม" + จุดเด่น 3 ข้อ
3. **แบบบ้าน Signature** — การ์ดแบบบ้าน กรองชั้นเดียว/สองชั้น เลื่อนซ้ายขวา
4. **ขั้นตอนดูแลครบวงจร** — 6 ขั้นตอน
5. **รีวิว** — รีวิวลูกค้า
6. **ติดต่อ** — ช่องทางติดต่อ + ฟอร์มขอคำปรึกษา

## ต้องแทนที่ก่อนใช้งานจริง
- `assets/logo-mark.svg` — โลโก้ชั่วคราว ให้ใช้ไฟล์โลโก้จริง
- `assets/hero-house.jpg` — ตัดจากภาพโพสต์ ความละเอียดต่ำ ควรใช้ภาพต้นฉบับความละเอียดสูง
- แบบบ้านใน `main.js` (`PLANS`) และภาพประกอบ `assets/house-*.svg` — เป็นข้อมูลตัวอย่าง
- รีวิวใน section 5 — เป็นตัวอย่าง ต้องใช้รีวิวจริงที่ลูกค้าอนุญาต
- ฟอร์ม: ใส่ URL รับข้อมูลที่ `data-endpoint` ของ `<form id="leadForm">` (เช่น Formspree / Google Apps Script)
- LINE ID (ยังไม่มีข้อมูล)
