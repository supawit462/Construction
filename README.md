# Baiboon Home — เว็บไซต์หน้าเดียว (React)

เว็บ one-page 6 section สำหรับ **Baiboon Home รับสร้างบ้านครบวงจร**
เขียนด้วย React + Vite ใช้ CI จากโพสต์รีแบรนด์ของเพจ และใช้โครงเว็บ pd.co.th เป็นแนวทาง

## เริ่มใช้งาน

```bash
npm install
```

```bash
npm run dev
```

```bash
npm run build
```

`npm run build` จะได้ไฟล์ `dist/index.html` ไฟล์เดียว (ฝังโค้ดทั้งหมดไว้ข้างใน)
- ดับเบิลคลิกเปิดดูในเครื่องได้เลย (ต้องต่ออินเทอร์เน็ตเพื่อโหลดรูปและฟอนต์)
- อัปโหลดขึ้นโฮสต์ static ได้ทันที เช่น Netlify, Vercel, GitHub Pages

## โครงสร้าง
```
src/
  data.js            ← ข้อความ รูป แบบบ้าน รีวิว ช่องทางติดต่อ (แก้ที่นี่ที่เดียว)
  App.jsx            ← ประกอบ 6 section
  hooks.js           ← เอฟเฟกต์ปรากฏ / ไฮไลต์เมนู
  styles.css         ← CI (สี ฟอนต์) และสไตล์ทั้งหมด
  components/
    Nav, Hero, About, Plans, Process, Reviews, Contact, Footer, Brand, Icon
  assets/            ← โลโก้ชั่วคราว ใบไม้ เกาะหญ้า
```

## 6 section
1. **Hero** — "เริ่มก้าวใหม่ที่อบอุ่น" + ภาพบ้านในกรอบโค้ง + การ์ดลอย
2. **เกี่ยวกับเรา** — ภาพทีมงาน + คำคม "ชื่อใหม่… แต่หัวใจเดิม" + จุดเด่น 3 ข้อ
3. **แบบบ้าน** — เสาสี 5 สไตล์บนเกาะหญ้า กดเลือกสไตล์เพื่อกรองการ์ดแบบบ้าน (กรองชั้นเดียว/สองชั้นได้ด้วย)
4. **ขั้นตอนดูแลครบวงจร** — 6 ขั้นตอน บนพื้นหลังภาพไซต์ก่อสร้าง
5. **รีวิว** — การ์ดรีวิวพร้อมภาพบ้าน
6. **ติดต่อ** — ช่องทางติดต่อ + ฟอร์มขอคำปรึกษา (กด "สอบถามราคา" ที่การ์ดแบบบ้าน จะเติมรหัสแบบในฟอร์มให้)

## รูปภาพ
รูปทั้งหมดโหลดจาก Unsplash (`images.unsplash.com`) ตาม Unsplash License — เปลี่ยนรูปได้ที่ `src/data.js`
โดยใส่รหัสรูป (ส่วน `photo-xxxx` ในลิงก์รูป) ลงในช่อง `id` / `photo`

## ต้องแทนที่ก่อนใช้งานจริง
- `src/assets/logo-mark.svg` — โลโก้ชั่วคราว ให้ใช้ไฟล์โลโก้จริง
- `PLANS` ใน `src/data.js` — แบบบ้านและรูปเป็นตัวอย่าง
- `REVIEWS` ใน `src/data.js` — รีวิวเป็นตัวอย่าง ต้องใช้รีวิวจริงที่ลูกค้าอนุญาต แล้วตั้ง `REVIEWS_ARE_SAMPLE = false`
- ฟอร์ม: ตั้งค่า `VITE_FORM_ENDPOINT` (เช่นในไฟล์ `.env`) เป็น URL รับข้อมูล เช่น Formspree / Google Apps Script
- LINE ID (ยังไม่มีข้อมูล)
